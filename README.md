# De Victoriano — премиальный лендинг

Адаптивная главная страница бренда мужских деловых костюмов. Проект сделан на HTML, CSS и JavaScript без сборщика и зависимостей.

## Запуск
Откройте `index.html` в браузере. Для локальной разработки можно использовать VS Code и расширение Live Server.

## Возможности
- Адаптивный дизайн для компьютеров и телефонов.
- Чёрно-золотая премиальная стилистика.
- Карточки товаров и демонстрационная корзина с подсчётом суммы и удалением товаров.
- Мобильная навигация.
- Демонстрационная форма подписки.
- Уважение системной настройки уменьшения анимации.

## Важно перед реальным запуском магазина
Корзина и форма подписки — только демонстрационные: реальные заказы и email не отправляются. Для продаж необходимо подключить backend или CRM, оплату и обработку заказов. Замените демонстрационные контакты, проверьте права на изображения и добавьте необходимые юридические документы, включая политику обработки персональных данных и условия продажи/доставки.

## Публикация на GitHub Pages
В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)** и нажмите **Save**. После публикации GitHub покажет адрес сайта в этом же разделе.
