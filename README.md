# De Victoriano — премиальный лендинг

Адаптивная демонстрационная главная страница бренда мужских деловых костюмов. Используются HTML, CSS, JavaScript и локальные SVG-иллюстрации; сборщик не нужен.

## Запуск
Откройте `index.html` в браузере. Для разработки можно использовать VS Code и расширение Live Server.

## Возможности
- Адаптивная вёрстка для компьютеров и телефонов.
- Чёрно-золотая премиальная стилистика.
- Локальные SVG-иллюстрации из папки `assets/` — без запросов к Unsplash.
- Системные шрифты — без зависимости от Google Fonts.
- Демонстрационная корзина с подсчётом суммы и удалением товаров.
- Мобильная навигация и анимации с поддержкой настройки уменьшения движения.
- Формы подписки и приёма заказов отключены; сайт не принимает данные через формы.

## Важно перед коммерческим запуском
Это дизайн-прототип, а не готовая торговая система. Реальные заказы и платежи не подключены. До сбора email, телефонов, адресов или других персональных данных необходимо определить оператора и цели обработки, подготовить документы и согласия, проверить требования 152-ФЗ, включая локализацию баз данных граждан РФ и применимость уведомления Роскомнадзора. Файл `privacy.html` — временное информационное уведомление, а не юридическая гарантия соответствия. Для коммерческого сайта с обработкой данных в РФ рассмотрите хостинг и backend с базами данных в России, после проверки всех потоков данных и договоров с провайдерами.

Также перед запуском проверьте юридические сведения продавца, условия оплаты, доставки и возврата, права на изображения и актуальные цены.

## Публикация на GitHub Pages
Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и нажмите **Save**. После публикации адрес появится в этом разделе. Обновления могут появляться не мгновенно.
